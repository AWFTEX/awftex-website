# AWFTEX Website 2.0

Premium static multi-page website for GitHub Pages. No backend or paid framework required.

## Publish
1. Create/open the GitHub repository used for awftex.com.
2. Upload all files and folders from this package to the repository root.
3. Commit the changes.
4. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
5. Keep the included `CNAME` file for `awftex.com`.

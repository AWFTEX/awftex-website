# AWFTEX Website

GitHub Pages-ready multi-page website for AWFTEX.

Custom domain: `awftex.com`

## Deployment

Replace the existing website files in the `main` branch with the contents of this package.

Keep the `CNAME` file at repository root.

The package includes the SEO structure, sitemap, robots.txt, favicon, Open Graph image, and multi-page HTML structure.

Note: only the image assets available in the working package are included. Existing product/project images from the live GitHub repository should be copied into `images/` if they are not already present.

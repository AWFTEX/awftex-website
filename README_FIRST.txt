SEO
---
Each page has a unique title, meta description, canonical URL, robots directives,
Open Graph/Twitter metadata, WebPage schema, Organization schema and breadcrumbs.
robots.txt and sitemap.xml are included.

IMPORTANT ASSET NOTE
--------------------
The original homepage references many existing images under /images/.
Only the AWFTEX logo plus generated favicon/social preview are supplied here,
because the original image assets were not separately uploaded in the conversation.
Keep your existing /images/ directory from the current GitHub project when deploying.

CONTENT NOTE
------------
The copy and terminology are based on the supplied AWFTEX homepage. Do not add
unsupported certifications, client names, addresses, product specifications,
prices or performance claims. Replace placeholder project/client content with
real evidence as those pages are populated.

DEPLOYMENT
----------
Upload the generated folders/files into the GitHub repository that serves
awftex.com. Make sure the custom domain remains awftex.com and that any www
variant redirects to the preferred canonical domain.

After publishing:
1. Open several pages directly to verify routing.
2. Check /robots.txt and /sitemap.xml.
3. Verify favicon and social preview.
4. Add/verify https://awftex.com/ in Google Search Console.
5. Submit https://awftex.com/sitemap.xml.
